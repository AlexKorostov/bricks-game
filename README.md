# Bricks - 3D Puzzle Game

A pseudo-3D tactical puzzle arcade game built with modern JavaScript and Three.js.

## 🚀 Quick Start

### 1. Install Dependencies
```bash
bun install
```

### 2. Development Server (with instant HMR)
```bash
bun run dev
```

### 3. Build Standalone Offline Single-File Game
```bash
bun run build
```
This bundles everything into a 100% self-contained offline HTML file at [`dist/bricks.html`](file:///Users/dev/projects/battle/dist/bricks.html) (and [`dist/index.html`](file:///Users/dev/projects/battle/dist/index.html)).

### 4. Run Unit Tests
```bash
bun test
```
